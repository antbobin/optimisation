# optimisation

Petit projet Python d'optimisation.

## Installation

```sh
python3 -m venv .venv
source .venv/bin/activate        # fish : source .venv/bin/activate.fish
pip install -e ".[dev]"
```

## Développement

```sh
pytest                  # lancer les tests
ruff check .            # linter
ruff format .           # formater le code
```
